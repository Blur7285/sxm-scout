# SXM Scout: Saint-Martin (French side)

A relocation planner for living on the French side of Saint-Martin. It runs entirely in the browser and can be installed as an app (PWA); it works offline.

- Your data is stored on your own device. Optionally it syncs to a shared folder in Google Drive after you sign in with Google.
- This repository contains no user data, tokens or secrets. A Google OAuth *client ID* is public by design and holds no secret.
- Served with GitHub Pages; `sw.js` uses network-first caching so new versions appear on the next load.
